## Neo4j Genealogy Simple Demo

This model shows raw material to intermediate to finished product and is modeled as a graph in Neo4j.
This simple model was built for our battery benchmark project.

The demo shows many to one and one to many relationships found in battery manufacturing steps.
The data is all made up from prior knowledge and google searches.

## How to run it

1. Create a free Neo4j AuraDB
2. Open the query editor (Neo4j Browser).
3. Paste the entire contents of the file and run it.
4. The graph will be created and automatically visualized.

## Sample Queries 
Sample queries are also included in the file where it allows you to trace raw materials up and down.
